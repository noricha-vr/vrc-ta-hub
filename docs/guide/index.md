# はじめに

技術・学術系イベントHub（以下、Hub）は、VRChat で開かれている技術・学術系の集会の予定と発表をまとめたサイトです。
このガイドでは、Hub の使い方を画面の画像つきで説明します。
Discord や VRChat を始めたばかりの人でも、上から順に読めば迷わず進められるように書いています。

## やりたいことから選ぶ

最初に読むページは、やりたいことで決まります。当てはまるものを 1 つ選んでください。

| やりたいこと | 最初に読むページ | アカウント |
| --- | --- | --- |
| 集会や発表を探したい・見に行きたい | [集会と発表を探す](browse/find.md) | いりません |
| 集会の予定を自分のカレンダーに入れたい | [予定を自分のカレンダーに追加する](browse/calendar.md) | いりません |
| 集会で発表したい | [発表を申し込む](speaker/apply.md) | いります |
| 自分の集会を Hub に載せたい | [集会を登録する](community/create.md) | いります |
| 集会のスタッフに招待された | [登録してログインする](account/login.md) | いります |
| 集会の開催日を登録・変更したい | [イベント管理画面の見方](event/manage.md) | いります（主催者・スタッフ） |
| 集会に届いた発表の申し込みを受けたい | [発表申請を承認・却下する](lt/approve.md) | いります（主催者・スタッフ） |

アカウントがまだ無い人は、どの場合も先に [登録してログインする](account/login.md) を読みます。

## 最低限の言葉

ガイドによく出てくる言葉です。ほかの言葉は [用語集](glossary.md) にまとめています。

| 言葉 | 意味 |
| --- | --- |
| 集会 | VRChat の中で定期的に開かれる勉強会や交流会のことです |
| イベント | 集会の 1 回分の予定です。「毎週土曜 22 時」の集会なら、1 回 1 回がイベントです |
| 発表（LT） | イベントの中で、テーマを決めて話す枠です。LT は 5〜10 分ほどの短い発表です |
| 主催者・スタッフ | 集会を運営する人です。主催者は集会の持ち主で、スタッフは主催者に招待されて手伝う人です |
| VRChat | アバターの姿で仮想空間に集まって話せるサービスです。集会はこの中の「ワールド」で開かれます |
| Discord | 文字や音声で会話できるアプリです。Hub へのログインや、集会の連絡に使います |
| サーバー・チャンネル | Discord の中のグループと、その中で話題ごとに分かれた部屋です |

## ガイドの読み方

- 各ページは「始める前に」「手順」「うまくいかない時」「次にやること」の順に並んでいます。
- 画像の赤い枠と丸の番号（①②）は、本文の ①② と対応しています。画像を押すと大きく表示されます。
- 「主催者のみ」の印があるページは、集会の主催者だけができる操作です。
- 困った時は [よくある質問](faq.md) を見てください。
