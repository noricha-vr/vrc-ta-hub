# スタッフの招待を受ける

招待された集会のスタッフとして参加します。
参加すると、集会情報や開催予定・発表を管理できます。

## 始める前に

- 主催者から届いた招待リンクを用意します。
- Hub のアカウントがなくても、招待画面から登録へ進めます。
- 招待リンクは相手だけに届く専用 URL です。公開の場所に貼らないでください。

## 手順

### 1. 招待リンクを開いてログインする

主催者から届いた招待リンクを開きます。招待された集会名が表示されているか確認します。

![未ログインの集会への招待で「ログイン」①を赤枠で示した画面](images/member/accept-01.webp)

① の「ログイン」を押して Hub にログインします。アカウントがなければログイン画面の案内から登録し、招待リンクをもう一度開きます。

### 2. 招待を受け入れる

ログイン後、同じ招待リンクを開きます。自動でスタッフ登録されるわけではありません。

![ログイン済みの集会への招待で「招待を受ける」①を赤枠で示した画面](images/member/accept-02.webp)

① の「招待を受ける」を押します。「スタッフになりました」と表示されれば完了です。[イベント管理画面](../event/manage.md)の「管理中の集会」で、招待された集会名を確認します。

## うまくいかない時

### リンクが開かない・期限切れになる

主催者に新しい招待リンクを送ってもらいます。
招待リンクの有効期限は、作成してから7日間です。

### 「既にこの集会のメンバーです。」と出る

参加済みです。集会名とログイン中のアカウントを確認します。
[管理する集会を切り替える](../community/switch.md)へ進みます。
