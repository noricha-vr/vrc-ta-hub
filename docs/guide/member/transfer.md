# 主催者を引き継ぐ

この操作は主催者だけができます。

引き継ぎリンクを渡し、相手の受け入れで主催者を交代します。受け入れが完了すると、元の主催者はスタッフになります。

## 始める前に

- 現在の主催者で Hub にログインしてください。受け入れは引き継ぎ先の人が行います。
- 相手の同意を先に確認します。相手は Hub のアカウントが必要ですが、既存スタッフである必要はありません。
- 引き継ぎリンクは7日間有効です。公開の場所には貼らず、引き継ぐ相手だけに渡します。
- 画像は作成前と発行後の状態を別の架空の集会で示しています。実際には同じ集会で進めます。

## 手順

### 1. 引き継ぎの確認を開く

[集会設定を開く](../community/settings.md)で対象集会を選び、「危険な操作」へ進みます。

![集会設定の危険な操作で「引き継ぎリンクを作成」①を赤枠で示した画面](images/member/transfer-01.webp)

① の「引き継ぎリンクを作成」を押します。

![スマホ幅の集会設定の危険な操作で「引き継ぎリンクを作成」①を赤枠で示した画面](images/member/transfer-01-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 2. リンクを作成する

確認画面を読みます。この時点では主催者は交代しません。相手の受け入れ後に権限が移ります。

![主催者引き継ぎの確認で「引き継ぎリンクを作成」①を赤枠で示した画面](images/member/transfer-02.webp)

① の「引き継ぎリンクを作成」を押します。やめる時は「キャンセル」を押します。

![スマホ幅の主催者引き継ぎの確認で「引き継ぎリンクを作成」①を赤枠で示した画面](images/member/transfer-02-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 3. リンクを相手に渡す

集会設定に「有効な引き継ぎリンクがあります」と表示されます。画像では URL を伏せています。

![有効な引き継ぎリンクの「コピー」①と「リンクを削除」②を赤枠で示しURLを伏せた画面](images/member/transfer-03.webp)

① の「コピー」を押し、相手だけに送るメッセージへ貼り付けます。受け入れ前に取り消す時は② の「リンクを削除」を押します。

![スマホ幅の有効な引き継ぎリンクの「コピー」①と「リンクを削除」②を赤枠で示しURLを伏せた画面](images/member/transfer-03-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 4. 受け取った人がログインする

ここからは引き継ぐ人が操作します。届いたリンクを開き、集会名と注意事項を確認します。

![未ログインの主催者引き継ぎ画面で「ログイン」①を赤枠で示した画面](images/member/transfer-04.webp)

① の「ログイン」を押します。アカウントがなければ登録後に、同じ引き継ぎリンクをもう一度開きます。

![スマホ幅の未ログインの主催者引き継ぎ画面で「ログイン」①を赤枠で示した画面](images/member/transfer-04-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 5. 主催者を引き継ぐ

ログイン後、同じリンクを開きます。受け入れる前に、引き継ぐ集会名をもう一度確かめます。

![ログイン済みの主催者引き継ぎ画面で「主催者を引き継ぐ」①を赤枠で示した画面](images/member/transfer-05.webp)

① の「主催者を引き継ぐ」を押します。ここで相手が主催者になり、元の主催者がスタッフになります。使用した引き継ぎリンクは削除されます。

![スマホ幅のログイン済みの主催者引き継ぎ画面で「主催者を引き継ぐ」①を赤枠で示した画面](images/member/transfer-05-sp.webp)

スマホでも同じ番号の箇所を操作します。

## うまくいかない時

### リンクを作っただけでスタッフになるのか

相手が「主催者を引き継ぐ」を押すまでは、現在の主催者のままです。確認画面はすぐ交代するようにも読めますが、交代は受け入れ時です。

### リンクが期限切れ・無効になった

現在の主催者が集会設定でリンクを作り直します。古いリンクが残っている場合は「リンクを削除」で取り消します。

### 完了した引き継ぎを元に戻したい

新しい主催者が引き継ぎリンクを作り、元の主催者が受け入れます。完了前なら「リンクを削除」で中止できます。

### 元の主催者が集会から離れたい

元の主催者はスタッフとして残ります。自分で脱退する機能はないため、新しい主催者に[スタッフの削除](remove.md)を依頼します。集会の完全削除を行う操作ではありません。
