# スタッフを招待する

この操作は主催者だけができます。

運営を手伝う人へ招待リンクを渡します。受け取った人がログインして「招待を受ける」を押すとスタッフになります。

## 始める前に

- 対象集会の主催者で Hub にログインしてください。招待の受け入れは、招待された人が操作します。
- 招待リンクは、受け取った人が開くための専用 URL です。公開の場所には貼らず、相手だけに送ります。
- スタッフは集会情報・通知・申請設定、開催予定や発表を管理できます。イベント削除・メンバー管理・閉鎖・再開・主催者引き継ぎは主催者の操作です。

## 手順

### 1. メンバー管理を開く

[集会設定を開く](../community/settings.md)で対象集会を選び、「メンバー管理」まで下へ進みます。

![集会設定のメンバー管理で「メンバーを管理」①を赤枠で示した画面](images/member/invite-01.webp)

① の「メンバーを管理」を押します。

![スマホ幅の集会設定のメンバー管理で「メンバーを管理」①を赤枠で示した画面](images/member/invite-01-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 2. 招待リンクを作る

別画面の「メンバー管理」が開きます。集会名を確認します。

![メンバー管理の「招待リンクを生成」①を赤枠で示した画面](images/member/invite-02.webp)

① の「招待リンクを生成」を押します。リンクは7日間有効です。

![スマホ幅のメンバー管理の「招待リンクを生成」①を赤枠で示した画面](images/member/invite-02-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 3. リンクをコピーして相手に渡す

「有効な招待リンク」に新しいリンクが表示されます。画像では URL を伏せています。

![有効な招待リンクのコピー用クリップボードアイコン①を赤枠で示しURLを伏せた画面](images/member/invite-03.webp)

① のクリップボードの形のアイコンを押します。Discord の DM（相手だけに送るメッセージ）などへ貼り付けて渡します。期限内は複数人が使えるため、相手を確かめて送ります。

![スマホ幅の有効な招待リンクのコピー用クリップボードアイコン①を赤枠で示しURLを伏せた画面](images/member/invite-03-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 4. 受け取った人がログインする

ここからは招待された人が操作します。届いたリンクを開き、集会名を確認します。

![未ログインの集会への招待で「ログイン」①を赤枠で示した画面](images/member/invite-04.webp)

① の「ログイン」を押して Hub にログインします。アカウントがなければログイン画面の案内から登録し、招待リンクをもう一度開きます。

![スマホ幅の未ログインの集会への招待で「ログイン」①を赤枠で示した画面](images/member/invite-04-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 5. 招待を受け入れる

ログイン後、同じ招待リンクを開きます。自動でスタッフ登録されるわけではありません。

![ログイン済みの集会への招待で「招待を受ける」①を赤枠で示した画面](images/member/invite-05.webp)

① の「招待を受ける」を押します。「スタッフになりました」と表示されれば完了です。主催者はメンバー管理の「メンバー一覧」で相手の名前を確認します。

![スマホ幅のログイン済みの集会への招待で「招待を受ける」①を赤枠で示した画面](images/member/invite-05-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 6. 使い終わったリンクを削除する

主催者は「メンバー管理」へ戻ります。まだ期限内でも、不要になったリンクは削除します。

![有効な招待リンクの削除用ごみ箱アイコン①を赤枠で示しURLを伏せた画面](images/member/invite-06.webp)

対象リンクの① ごみ箱アイコンを押します。ブラウザの確認で「OK」を押します。やめる時は「キャンセル」を押します。リンクの削除では、参加済みのスタッフは削除されません。

![スマホ幅の有効な招待リンクの削除用ごみ箱アイコン①を赤枠で示しURLを伏せた画面](images/member/invite-06-sp.webp)

スマホでも同じ番号の箇所を操作します。

## うまくいかない時

### リンクが開かない・期限切れになる

主催者が新しい招待リンクを生成し、渡し直します。スタッフ用のリンクは誰かが使っても消費されません。有効期限内なら複数人が使えます。

### 「既にこの集会のメンバーです。」と出る

そのアカウントは参加済みです。集会名を確認し、[管理する集会を切り替える](../community/switch.md)へ進みます。

### メンバー管理が見えない

主催者だけが招待できます。スタッフは主催者へ招待を依頼してください。主催者向けの操作は閉鎖・再開で、集会の完全削除機能はありません。
