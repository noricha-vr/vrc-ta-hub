# スタッフを削除する

この操作は主催者だけができます。

集会のメンバーからスタッフを外します。Hub のアカウントや、その人が登録した発表は削除されません。

## 始める前に

- 対象集会の主催者で Hub にログインしてください。
- 外す相手の名前を確認してください。同じ名前が並ぶ時は Discord 連携の有無や登録日も確認します。
- 外された人は、その集会の管理権限を失います。

## 手順

### 1. メンバー管理を開く

[集会設定を開く](../community/settings.md)で対象集会を選び、「メンバー管理」へ進みます。

![集会設定のメンバー管理で「メンバーを管理」①を赤枠で示した画面](images/member/remove-01.webp)

① の「メンバーを管理」を押します。

### 2. 相手を確認して削除する

「メンバー一覧」で相手を探します。表示名・「スタッフ」の表示・Discord 連携の有無・登録日を確認します。

![メンバー一覧で対象者の情報①、「メンバーを削除…」②、確認欄の「メンバーを削除する」③を赤枠で示した画面](images/member/remove-02.webp)

① の相手で間違いなければ、同じ行の②「メンバーを削除…」を押します。開いた確認欄でも名前と役割を読み、③ の「メンバーを削除する」で確定します。画像では確認欄を開いています。

やめる時は「キャンセル」を押します。確定後、メンバー一覧から相手が消えたことを確認します。

## うまくいかない時

### 自分で脱退したい

スタッフ本人向けの「脱退」ボタンはありません。主催者へ削除を依頼します。

### 主催者を削除したい

主催者は自分自身を削除できません。[主催者を引き継ぐ](transfer.md)で引き継ぎを済ませた後、新しい主催者へ自分の削除を依頼します。

### 間違えて削除した

[スタッフを招待する](invite.md)に沿って招待し直します。メンバー削除では、その人が登録したイベントや発表は消えません。
