# 用語集

ガイドに出てくる言葉を、はじめての人向けに一言で説明します。分からない言葉が出てきたら、このページに戻ってきてください。

## Hub の言葉

| 言葉 | 意味 |
|------|------|
| Hub | このサイト（技術・学術系イベントHub）のことです。VRChat の技術・学術系の集会の予定や発表をまとめています |
| 集会 | VRChat の中で定期的に開かれる勉強会や交流会のことです。Hub には集会ごとにページがあります |
| イベント（開催回） | 集会が開く 1 回分の予定です。「毎週土曜 22 時」の集会なら、1 回 1 回がイベントです |
| 発表（LT） | イベントの中で、テーマを決めて話す枠です。LT（ライトニングトーク）は 5〜10 分ほどの短い発表のことです |
| 主催者 | 集会の持ち主です。集会の情報を編集できるほか、スタッフの招待・集会の閉鎖・主催者の引き継ぎができます |
| スタッフ | 主催者に招待されて、集会の運営を手伝う人です。イベントや発表を管理できます |
| Hub 運営 | サイト全体を管理する人です。集会の登録を審査します。集会のスタッフとは別です |
| 発表申請 | 発表したい人が、集会に「この日に発表したい」と申し込むことです。主催者・スタッフが承認すると発表が決まります |
| 承認待ち・承認済み・却下 | 登録や申請の状態です。それぞれ「確認中」「受け入れた」「受け入れなかった」の意味です |
| 開催周期 | 「毎週」「隔週」「毎月第 2 土曜」など、イベントを繰り返す間隔です |
| アカウントの紐づけ | Hub に登録された発表と、発表した本人の Hub のアカウントをつなぐことです |
| 発表の記事化 | 発表の動画や資料から、Hub が記事を作って載せてよいかどうかの選択です |
| 撮影許可 | 集会や発表を撮影・録画してよいかどうかの設定です |

## Discord の言葉

Discord（ディスコード）は、文字や音声で会話できるアプリです。多くの集会が、連絡やお知らせに使っています。

| 言葉 | 意味 |
|------|------|
| サーバー | Discord の中の、ひとつのグループの場所です。集会ごとにサーバーを作ることが多いです |
| チャンネル | サーバーの中で、話題ごとに分かれた部屋です（例:「#お知らせ」「#雑談」） |
| ロール | サーバーの中で、メンバーに付ける役割です（例:「スタッフ」）。ロールごとに通知したり権限を変えたりできます |
| メンション | 「@名前」の形で、特定の人やロールに通知を送ることです |
| Webhook（ウェブフック） | Hub から Discord のチャンネルへ、自動でお知らせを送るための仕組みです |
| Webhook URL | Webhook の送り先を表す URL です。知っている人なら誰でもそのチャンネルに投稿できてしまうので、他の人に見せないでください |
| Discord 連携 | Hub のアカウントと Discord のアカウントをつなぐことです。つなぐと Discord でログインできます |

## VRChat の言葉

VRChat（ブイアールチャット）は、アバターの姿で仮想空間に集まって話せるサービスです。

| 言葉 | 意味 |
|------|------|
| ワールド | VRChat の中の仮想空間です。集会はワールドの中で開かれます |
| インスタンス | 同じワールドに作られる、ひとつひとつの部屋です。同じワールドでも、インスタンスが違うと会えません |
| グループ | VRChat の中でメンバーをまとめる仕組みです。集会の参加案内によく使います |
| グループジョイン | グループが用意したインスタンスに入ることです。集会の参加方法としてよく使います |
| フレンド申請 | VRChat で相手をフレンドに登録するための申し込みです |
| プラットフォーム | VRChat に参加する環境の種類です。パソコン（PC）か、Meta Quest などの単体で動く機器（モバイル）かを指します |

## その他の言葉

| 言葉 | 意味 |
|------|------|
| URL | Web ページの住所です（例: `https://vrc-ta-hub.com/`） |
| PDF | 文字や図の見た目を保ったまま共有できる資料のファイル形式です |
| スライド URL | インターネットで公開した発表資料を開くためのリンクです |
| サムネイル | 一覧などに出る、小さな紹介画像です |
| Markdown | 「# 見出し」のように記号を使って文章の見た目を指定する書き方です |
| API・API キー | 別のプログラムから Hub の情報を読み書きするための窓口と、その利用者を確かめるための秘密の文字列です |
| QR コード | スマートフォンのカメラで読み取ると URL が開く、四角い図です |
| CSV | 表のデータを、表計算ソフトで開ける形で保存したファイルです |
