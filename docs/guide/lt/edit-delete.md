# 発表情報を編集・削除する

登録済みの発表の内容や資料を更新します。
不要になった発表は「イベント管理」から削除します。

## 始める前に

- ログインして、対象集会の「イベント管理」を開きます。
- 開き方は[発表情報を登録する](create.md)の手順 1 を参照します。
- このページは対象集会の主催者・スタッフ向けです。

紐づけ済みの発表者本人も、承認済みの発表を編集できます。
本人は開始時間・持ち時間の変更や削除はできません。

## 手順

### 1. 発表の編集画面を開く

開催日とテーマを確認して対象の発表を探します。

![イベント管理の発表にある「編集」を赤枠①で示した画面](images/lt/edit-delete-01.webp)

① の「編集」を押します。
発表の詳細画面にある「編集」からも開けます。

### 2. 資料や画像を差し替える

開催前は「詳細設定を表示」を押します。
基本項目を直す場合は「テーマ」などを直接修正します。

![編集フォームのスライド選択欄を①、サムネイル画像の選択欄を②の赤枠で示した画面](images/lt/edit-delete-02.webp)

① の「スライド」で新しい PDF を選びます。
画像を変える場合は ② の「サムネイル画像」を選び直します。
既存ファイルの「クリア」は、そのファイルを外す時に使います。

PDF は最大 30MB、画像は最大 10MB です。
画像は中央を基準に横長に切り取られます。
「スライド URL」は外部の資料へのリンクです。

### 3. 記事の内容を修正して保存する

生成済みの記事も自分で書き直せます。
[用語集](../glossary.md)の Markdown の説明も参照します。

![タイトル(H1)を①、内容を②、保存を③の赤枠で示した編集画面](images/lt/edit-delete-03.webp)

① の「タイトル(H1)」と ② の「内容」を修正します。
③ の「保存」を押します。
詳細画面で変更後の内容を確認します。

「発表の記事化」は発表者の選択結果です。
主催者・スタッフはこの画面で変更できません。

### 4. 不要な発表を削除する

削除する時だけ「イベント管理」へ戻ります。
同じ開催日の別の発表と取り違えないよう確認します。

![イベント管理の発表にある「削除」を赤枠①で示した画面](images/lt/edit-delete-04.webp)

① の「削除」を押します。
「本当に削除しますか？」と出たら内容を確認します。
削除する場合だけ、確認画面の OK を押します。

取りやめる時はキャンセルを押します。
ブラウザにより確認ボタンの表記は異なります。
削除した発表は一覧から消えます。

## うまくいかない時

### 開始時間や持ち時間を変更できない

発表者本人には日時の変更権限がありません。
変更する時は主催者・スタッフに依頼します。
Vket コラボ対象の発表では主催側にも日時制限があります。

### 削除が制限されていると表示される

Vket コラボの対象期間などは削除できない場合があります。
画面の案内に従い、運営へ相談します。

### 編集したい発表が見つからない

管理中の集会と開催日を確認します。
発表者本人はアカウント設定の「自分の発表」を開きます。
紐づけがまだなら、主催者にリンクの発行を依頼します。
