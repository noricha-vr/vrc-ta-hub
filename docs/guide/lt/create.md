# 発表情報を登録する

開催回に発表を追加します。
「特別企画」や「ブログ」も同じ画面で登録します。
保存すると、登録した内容の詳細画面が開きます。

## 始める前に

- 技術・学術系イベントHub にログインします。
- 対象の集会の主催者かスタッフであることを確認します。
- [イベントを登録する](../event/create.md)の手順で、開催回を用意します。
- 発表者とテーマ、開始時間、持ち時間を決めます。

発表者本人からの申し込みは、集会の公開ページから行います。
このページの登録画面は、主催者・スタッフ向けです。

## 手順

### 1. 管理する集会を開く

右上のアカウントメニューを開きます。
スマホでは先に右上の三本線を押します。

![アカウントメニューで「さくら技術交流会」を赤枠①で示した画面](images/lt/create-01.webp)

① の集会名を押すと「イベント管理」が開きます。
「管理中の集会」の下の集会名を確認します。

### 2. 発表の登録画面を開く

「イベント管理」で、登録する開催日を探します。

![開催回の「発表を追加」を赤枠①で示した画面](images/lt/create-02.webp)

開催回のカードの下端にある、① の「発表を追加」を押します。

### 3. 発表内容を入力する

「発表の追加」の見出しで、集会名と開催日時を確認します。
「発表内容」のカードで、「タイプ」の「発表」を選びます。

![「発表内容」のタイプの「発表」①、テーマ②、発表者名③を赤枠で示した入力画面](images/lt/create-03.webp)

① の「発表」を選び、② に「テーマ」を入力します。
③ の「発表者名」には、ログイン中のあなたの表示名が入っています。
別の人の発表なら、その人の VRChat の表示名に書き換えます。

| 項目 | 何を入れるか | 必須か |
|---|---|---|
| ② テーマ | 発表の題名 | 必須 |
| ③ 発表者名 | 発表する人の名前 | 必須 |

### 4. 開始時間と持ち時間を入力する

「発表内容」のカードで、発表の時間を確認します。
「開始時間」には、申請と同じ時刻（前の発表の後か、集会設定の「最初の発表を始めるタイミング」）が入っています。
「発表の持ち時間（分）」には、集会設定の持ち時間が入っています。
どちらも変更できます。

![開始時間①と発表の持ち時間②を赤枠で示した画面](images/lt/create-04.webp)

必要なら ① の「開始時間」と ② の「発表の持ち時間（分）」を直します。

| 項目 | 何を入れるか | 必須か |
|---|---|---|
| ① 開始時間 | 発表を始める時刻 | 必須 |
| ② 発表の持ち時間（分） | 発表する分数。1 分以上 | 必須 |

### 5. X アカウント、撮影、記事化、追加情報を入力する

発表申請と同じ項目を入力します。

![X アカウント①、撮影②、発表の記事化③、追加情報④を赤枠で示した画面](images/lt/create-05.webp)

① の「X (Twitter) アカウント」は、発表者名があなたの表示名と同じ時だけ使います。
Hub の X の告知に @ID を載せ、あなたのアカウントにも保存します。

② の「撮影」と ③ の「発表の記事化」は、発表者と確認した選択肢を選びます。
④ の「追加情報」は、発表について残しておきたいことを書きます。
この欄は公開されるので、連絡先などは書きません。
集会にテンプレートがある時は、その内容が入っています。
テンプレートのままでは保存できないので、書き足すか消してください。

| 項目 | 何を入れるか | 必須か |
|---|---|---|
| ① X (Twitter) アカウント | 自分の発表の時の @ID。URL でも可 | 任意 |
| ② 撮影 | 撮影・動画公開をどこまで許可するか | 欄が出る時に選択 |
| ③ 発表の記事化 | 動画や PDF から記事を作ってよいか | 必須 |
| ④ 追加情報 | 補足。テンプレートがあれば沿って書く | 任意 |

集会が撮影を許可していない時は、撮影の選択欄が出ません。

### 6. 詳細設定を開く

開催前の「発表」は、資料などの欄が隠れています。
資料を後から登録する時も同じ操作です。

![「詳細設定を表示」を赤枠①で示した画面](images/lt/create-06.webp)

「追加情報」の下にある ① の「詳細設定を表示」を押します。
「資料」のカードと、「記事」の入力欄が出ます。
開催済みの場合は、初めから資料などの欄が出ます。

### 7. 資料や記事の情報を入力する

「資料」に PDF や動画のリンクを入力します。
記事の題名や本文は、その下の「記事」に入力します。
資料がまだない場合は、空欄のまま先へ進めます。

![「PDF をアップロード」を①、「リンクから読み込む」を②、サムネイル画像を③の赤枠で示した画面](images/lt/create-07.webp)

① の「PDF をアップロード」か、② の「リンクから読み込む」を選びます。
PDF を使う時は「スライドの PDF」でファイルを選びます。
リンクを使う時は「スライドのリンク」に URL を貼り付けます。
③ の「サムネイル画像」は記事上部の画像です。

| 項目 | 何を入れるか | 必須か |
|---|---|---|
| スライドの PDF | 公開ページから開ける PDF。最大 30MB | 任意 |
| スライドのリンク | 外部の資料ページの URL。Speaker Deck は PDF を読み込みます | 任意 |
| 記事に使う PDF | 読み込めないリンクで記事を作るための PDF。PDF 自体は公開されず、1 枚目だけサムネイルになります | 任意 |
| ③ サムネイル画像 | 最大 10MB の画像 | 任意 |
| YouTube URL | 発表の動画 URL。Discord メッセージのリンクも入力可能 | 任意 |
| タイトル(H1) | 記事の見出し。空欄ならテーマを使用 | 任意 |
| 内容 | 記事の本文。[用語集](../glossary.md)の Markdown も参照 | 任意 |
| 記事を自動生成する | PDF・動画から記事を作る時にチェック | 任意。表示される時だけ |

Speaker Deck のリンクは保存後に PDF を読み込み、記事に使います。
SlideShare などほかのリンクは読み込めないので、「記事に使う PDF」をアップロードするか、動画を追加します。
リンクがある発表の公開ページは、PDF を登録していてもリンク先へ案内します。
サムネイル画像は横長のスライド比率に切り取られます。
端にある文字は切れることがあります。

### 8. 特別企画やブログの場合はタイプを変える

発表者のいない企画は「特別企画」を選びます。
開催回の振り返りなどの記事は「ブログ」を選びます。
通常の発表を登録する場合は、この手順を飛ばします。

![「特別企画」を①、開始時間を②、タイトル(H1)を③の赤枠で示した画面](images/lt/create-08.webp)

① の「特別企画」を選びます。
② の「開始時間」と ③ の「タイトル(H1)」を入力します。
下にある「内容」に企画の説明を書きます。

![「ブログ」を①、タイトル(H1)を②、内容を③の赤枠で示した画面](images/lt/create-09.webp)

ブログなら ① の「ブログ」を選びます。
② に題名、③ に本文を書きます。

| タイプ | 表示される主な項目 | 発表との違い |
|---|---|---|
| 特別企画 | 開始時間、サムネイル画像、タイトル(H1)、内容 | テーマ・発表者・持ち時間・スライド・動画の入力欄は出ません |
| ブログ | サムネイル画像、タイトル(H1)、内容 | 開始時間も入力しません。本文は自分で書きます |

題名と本文は「記事」のカードにあります。
「タイトル(H1)」と「内容」は空でも保存できます。
読む人に伝わる題名と本文を入力してください。

### 9. 保存する

入力した内容を確認します。
画面下の操作バーに「未保存の変更があります」と出ます。

![画面下の操作バーの「保存」を赤枠①で示した画面](images/lt/create-10.webp)

① の「保存」を押します。
詳細画面が開いたら、題名や発表者を確認します。
記事の生成を伴う時は、画面が切り替わるまで待ちます。

## うまくいかない時

### 集会名や「発表を追加」が見つからない

別のアカウントでログインしていないか確認します。
対象集会の主催者にスタッフ登録を確認してもらいます。
主催者・スタッフが登録できるのは管理する集会だけです。

### 「テーマを入力してください。」と表示される

「タイプ」が「発表」の時はテーマと発表者が必須です。
開始時間と持ち時間も入力し直して「保存」を押します。

### PDF や画像を選べない

PDF は 30MB 以下、サムネイル画像は 10MB 以下にします。
ファイルを小さくして選び直します。

### 「発表の記事化」を選ぶ欄がない

既存発表の編集画面では、発表者の選択結果を表示します。
主催者・スタッフはこの画面で OK / NG を変更しません。
