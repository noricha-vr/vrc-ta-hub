# Vketコラボに参加登録する

集会として Vket コラボへの参加を申し込みます。
希望の日程と発表内容を保存し、参加状況を確認します。

## 始める前に

- 参加する集会の主催者かスタッフでログインします。
- アカウントのメニューで、操作する集会を選びます。
- コラボの開催期間内に、集会のイベント日程を登録しておきます。
- コラボは、複数の集会が参加する合同企画です。画像の「デモコラボ 2030」と日付は架空です。

[コラボ一覧](https://vrc-ta-hub.com/vket/)では、各企画の期間と受付状況を確認できます。
「詳細を見る」の先には「スケジュール（確定分）」があります。
これらの公開情報は、ログインせずに読めます。

## 手順

### 1. コラボの参加登録を開く

イベント管理画面で、コラボの案内を探します。

![イベント管理のコラボ案内で参加状況を開くボタンを赤枠①で示した画面](images/vket/apply-01.webp)


① のボタンから参加状況を開きます。
未登録なら「参加登録する」、登録済みなら日程情報の「編集」を押します。
案内されたコラボの詳細ページからも進めます。

![コラボ詳細の「参加登録」ボタンを赤枠①で示した画面](images/vket/apply-02.webp)


詳細ページでは、開催期間と締切を読み、① の「参加登録」を押します。

### 2. 参加希望日を選ぶ

画面の集会名が、申し込みたい集会か確認します。

![参加登録の「参加希望日」の選択肢を赤枠①で示した画面](images/vket/apply-03.webp)


① で日付を選びます。
出てくるのは、コラボ期間内に登録済みの開催日です。
希望の日がなければ「イベント日程を追加」から先に日程を登録します。

### 3. 開始時刻と開催時間を入れる

![参加登録の「開始希望時刻」を赤枠①、「希望開催時間（分）」を赤枠②で示した画面](images/vket/apply-04.webp)


① に開始時刻を入れ、② で開催時間を選びます。
「埋まっている時間」に他の集会の時間が出る場合は、見比べて決めます。
重なりの警告が出ても保存はできます。日程の調整は運営に相談してください。

### 4. 決まっている発表を入力する

発表情報は、今は空欄でも申し込めます。
決まっている場合は「1人あたりの持ち時間（分）」を選びます。
発表と質問への回答を合わせた時間です。

![発表情報で「登壇者名」を赤枠①、「テーマ」を赤枠②、「発表開始時刻」を赤枠③で示した画面](images/vket/apply-05.webp)


① に名前、② に話すテーマを入れます。
③ に発表の開始時刻を入れます。
未入力なら、集会の開始時刻や前の発表から補われます。
次の人を登録する時は「発表を追加」を押します。

### 5. 備考を書いて保存する

![参加登録の「備考」の入力欄を赤枠①で示した画面](images/vket/apply-06.webp)


① に運営への連絡を入れます。
当日の案内などを手伝ってほしい場合は「サポート希望」と書きます。

![参加登録フォームの末尾で「保存する」を赤枠①で示した画面](images/vket/apply-07.webp)


① の「保存する」を押します。
「参加登録を保存しました。」と表示され、参加状況が開きます。

### 6. 希望日程と確定日程を確認する

![参加状況の「日程情報」で希望日程と確定日程が並び、「編集」を赤枠①で示した画面](images/vket/apply-08.webp)


「希望日程」は申し込んだ内容です。「確定日程」は確定処理後の内容です。
変更したい時は、① の「編集」から同じフォームを開きます。
保存後すぐに確定日程が変わるわけではありません。
次の自動確定で反映されるため、あとで確定日程も確認します。

## うまくいかない時

### 登録した発表を取り下げたい

発表の編集受付中は、参加状況の対象発表に「削除」が出ます。
削除すると元に戻せず、公開中の発表は次の自動確定で取り下げられます。
削除する発表を確認し、確認画面で確定してください。

### 日付の選択肢がない

その集会の開催日が、コラボの期間内に登録されていません。
「イベント日程を追加」で日程を作り、参加登録を開き直します。

### 受付期間外と表示される

新規の参加表明は、参加受付中で締切内の場合に行えます。
申込み済みの場合は、発表の編集受付中なら日程も変更できます。
開催期間の終了後や確定・アーカイブ状態では編集できません。
変更できない場合はコラボ運営に相談してください。

### 希望と確定の内容が違う

保存した変更は、次の確定まで希望欄に残ります。
公開済みの発表も、次の反映まで前の内容が残る場合があります。
急ぎの変更は、コラボ運営に伝えてください。
