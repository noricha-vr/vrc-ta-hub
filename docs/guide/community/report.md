# 活動停止を通報する

開催されていない可能性がある集会を Hub 運営へ知らせます。ログインせずに送信できます。

## 始める前に

- 集会の参加案内や開催予定を確認してください。活動停止の可能性を知らせるための機能です。
- 承認済みで、終了日が設定されていない集会にボタンが表示されます。
- 通報内容は Hub 運営だけが確認します。送信元の IP アドレスは記録されます。

## 手順

### 1. 対象集会の通報ボタンを開く

画面の「集会一覧」から対象集会を開きます。スマホで見つからない時は、先に三本線のメニューを開きます。集会名を確認してページの下へ進みます。

![集会詳細下部の「この集会が開催されていないかもしれない」①を赤枠で示した画面](images/community/report-01.webp)

① の「この集会が開催されていないかもしれない」を押します。

![スマホ幅の集会詳細下部の「この集会が開催されていないかもしれない」①を赤枠で示した画面](images/community/report-01-sp.webp)

スマホでも同じ番号の箇所を操作します。

### 2. 内容を確認して通報する

「活動停止の通報」の説明を読みます。通報だけで直ちに集会が非公開になるわけではありません。

![活動停止の通報確認で「通報する」①を赤枠で示した画面](images/community/report-02.webp)

① の「通報する」を押します。「通報を受け付けました。ご協力ありがとうございます。」と表示されます。やめる時は「キャンセル」を押します。

![スマホ幅の活動停止の通報確認で「通報する」①を赤枠で示した画面](images/community/report-02-sp.webp)

スマホでも同じ番号の箇所を操作します。

## うまくいかない時

### 「すでに通報済みです。」と表示される

同じ接続元（IP アドレス）から同じ集会への通報は、30日間に1回までです。アカウントを変えても制限は共通です。

### 他の集会も通報したい

同じ接続元からは合計3件までの制限があります。暦月ごとのリセットではなく、30日間の有効期間で数えます。上限時も受付と同じ表示になるため、繰り返し送信しないでください。

### ボタンがない・間違えて送った

終了日がある集会にはボタンが出ません。送信を取り消す画面はありません。Hub 運営が実際の活動状況を確認します。

### サイトの不具合を知らせたい

活動停止以外の問題は、[GitHub のお問い合わせ先](https://github.com/noricha-vr/vrc-ta-hub/issues)へ知らせます。
