# 集会情報を編集する

集会の紹介・開催情報・リンク・ポスターを更新します。主催者とスタッフが同じフォームを使います。

## 始める前に

- Hub にログインしてください。対象集会の主催者かスタッフであることが必要です。
- 複数の集会を管理している時は、更新する集会名を確認します。

## 手順

### 1. 対象集会の設定を開く

画面上部の人の形のアイコンから、自分の表示名を押します。スマホは先に三本線のメニューを開きます。

![アカウント設定の対象集会の「設定」を赤枠①で示した画面](images/community/edit-01.webp)

アカウント設定の「管理中の集会」で、対象集会の①「設定」を押します。

### 2. 基本情報の入力欄を確認する

設定画面上部の集会名を確認します。この画面で直接編集します。

![集会設定の基本情報で集会名の入力欄を赤枠①で示した画面](images/community/edit-02.webp)

① の「集会名」から変更する欄を確認します。

### 3. 集会名と開催情報を変更する

「基本情報」の各欄を変更します。

| 項目 | 何を入れるか | 必須か |
|---|---|---|
| 集会名 | 公開する名前。100文字以内 | 必須 |
| 開始時刻 | 開始する時刻 | 必須 |
| 開催時間 | 開催する分数 | 必須 |
| 曜日 | 開く曜日 | 任意 |
| 開催周期 | 毎週・不定期などの案内。100文字以内 | 必須 |

ここで「開催周期」を書き換えても、登録済みの開催予定は変更されません。開催回の管理は[イベント登録](../event/create.md)を確認します。

![編集フォームの集会名①と開催周期②を赤枠で示した画面](images/community/edit-03.webp)

① は公開名、② は紹介用の開催周期です。開始時刻・開催時間・曜日も見直します。

### 4. リンク・ポスター・紹介を変更する

「主催と連絡先」、続いて「掲載内容」へ進みます。

| 項目 | 何を入れるか | 必須か |
|---|---|---|
| 主催・副主催 | 公開する名前。200文字以内 | 必須 |
| VRChatグループURL / 主催プロフィールURL | VRChat の参加先・主催者のリンク | 任意 |
| XアカウントURL / Xハッシュタグ | 集会の X のリンク・「#」付きの言葉 | 任意 |
| Discordサーバー | 連絡場所に入るための招待リンク | 任意 |
| ポスター | 変更する時だけ JPEG・PNG を選択 | 任意 |
| 集会を紹介するためのポスター転載を許可する | 紹介への転載を認めるならチェック | 任意 |
| 集会紹介 | テーマ・対象者・参加案内 | 任意 |
| 対応プラットフォーム | 参加できる機器の種類 | 必須 |
| タグ | 技術系集会・学術系集会を選択 | 任意 |

「現在のポスター」は保存済みの画像です。新しく選んだ画像のプレビューではありません。画像は A4比率・縦4096px が推奨です。保存時は長辺4096px以下に調整・再圧縮されます。

![編集フォームのポスター①、集会紹介②、タグ③を赤枠で示した画面](images/community/edit-04.webp)

① で新しい画像を選びます。変更しない時は選ばずに進みます。② は集会紹介、③ はタグです。

### 5. 更新を確定する

変更すると、画面下の保存欄に「集会情報を保存」が出ます。変更内容を確認します。

![画面下の「集会情報を保存」を赤枠①で示した画面](images/community/edit-05.webp)

① の「集会情報を保存」を押します。集会設定へ戻り、「集会情報を更新しました。」と表示されれば完了です。

## うまくいかない時

### 別の集会が表示される

[管理する集会を切り替える](switch.md)で対象を選び直します。

### 保存ボタンや「参加方法」が見つからない

集会情報を変更すると、画面下に「集会情報を保存」が出ます。発表の受付と通知は別の保存ボタンです。ひとつずつ変更・保存します。

「参加方法」は集会情報の欄にはありません。集会設定の「カレンダー設定」で扱います。汎用の Web サイト欄もありません。

### ポスターを更新できない

JPEG・PNG で選び直します。新規登録時の画面には30MBの案内があります。大きい画像は30MB以内を目安に小さくしてから選び直します。フォームの「原本を保持」という表記にかかわらず、元の画像は手元に保管してください。
