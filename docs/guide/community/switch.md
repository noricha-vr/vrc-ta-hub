# 管理する集会を切り替える

複数の集会に所属している時に、編集する集会を選び直します。集会名を確認してから操作を続けます。

## 始める前に

- Hub にログインしてください。切り替え先の主催者かスタッフであることが必要です。
- ここで選ぶのは管理する対象です。主催者の権限を他の人へ渡す操作ではありません。

## 手順

### 1. アカウント設定を開く

画面上部の人の形のアイコンを押します。スマホは先に三本線のメニューを開きます。

![アカウントメニューの自分の表示名を赤枠①で示した画面](images/community/switch-01.webp)

① の自分の表示名を押します。

### 2. 切り替え先の集会を選ぶ

アカウント設定の「管理中の集会」で、管理したい集会の行を探します。

![所属集会の名前①と「設定」②を赤枠で示した画面](images/community/switch-02.webp)

① の集会名を押すと、その集会のイベント管理へ進みます。設定を変えたい時は② の「設定」を押します。

### 3. イベント管理から切り替える

イベント管理では、「管理中の集会」の下の集会名からも選べます。所属集会が1つの時は選択メニューが出ません。

![イベント管理の集会名メニュー①と切り替え先の集会②を赤枠で示した画面](images/community/switch-03.webp)

① の集会名を押し、② の切り替え先を押します。「管理中の集会」の下の集会名が変わったことを確認します。

## うまくいかない時

### 切り替え先が一覧にない

所属する集会だけが表示されます。主催者へ[スタッフの招待](../member/invite.md)を依頼します。

### 「終了」と表示されて選べない

終了した集会は管理対象へ切り替えられません。主催者が[集会を再開](close.md)してから選びます。

### 編集する集会を間違えそう

イベント管理の見出し、または集会設定上部の集会名を毎回確認します。
