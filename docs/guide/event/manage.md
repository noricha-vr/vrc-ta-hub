# イベント管理画面の見方

集会の開催予定と発表を管理する入口を確認します。
番号付きの地図から、やりたい操作へ進めます。

## 始める前に

- 技術・学術系イベントHub にログインします。
- 管理したい集会の主催者かスタッフであることを確認します。
- イベントは、集会を開く「1 回分の予定」です。
- 役割や言葉が分からない時は、[用語集](../glossary.md)を開きます。

## 手順

### 1. アカウントメニューから集会を開く

画面上部の人型アイコンを押します。
スマホでは、先に右上の三本線を押します。

![人型のアカウントメニューに①、所属する「さくら技術交流会」に②の赤枠がある画面](images/event/manage-01.webp)

① のアカウントメニューから、② の集会名を押します。
「イベント管理:」の後に、選んだ集会名が出ます。

![スマホで開いたアカウントメニューの①と集会名の②を赤枠で示した画面](images/event/manage-01-sp.webp)

スマホでも、① を開き、② の集会名を押します。
「集会一覧」という項目を探す必要はありません。

### 2. 地図からやりたい操作を選ぶ

上部は集会全体の操作です。
その下のカード 1 枚が、1 回分の開催予定です。
下の表で番号を探し、対応するガイドを開きます。

![イベント管理の上部メニュー①〜⑥、開催日時と告知・削除⑦〜⑩、発表の操作⑪⑫、発表を追加⑬に赤枠がある地図](images/event/manage-02.webp)

①〜⑥ は集会全体、⑦〜⑩ は開催回、⑪〜⑬ は発表の操作です。
画像を押すと大きく開けます。

| 番号 | 画面の表示 | 押すと何が起きるか・進む先 |
|---|---|---|
| ① | イベント登録 | 新しい開催日を作ります。[イベントを登録する](create.md)へ進みます。 |
| ② | 発表申請一覧 | **自分が発表者として申し込んだ分**を確認します。主催側の承認待ち一覧ではありません。[発表申請一覧を開く](/account/lt-applications/)を押します。 |
| ③ | アクセス | 集会や発表の閲覧数を調べます。[アクセス解析を開く](/analytics/dashboard/)を押します。 |
| ④ | 発表履歴 | 過去の発表を探します。[発表履歴を開く](/event/detail/history/)を押します。 |
| ⑤ | 集会設定 | 集会情報や外部との連携を設定します。[集会設定](../community/settings.md)へ進みます。 |
| ⑥ | 公開ページ | 参加者が見る集会の紹介ページを開きます。開催予定の見え方を確認します。 |
| ⑦ | 鉛筆アイコン（開始時刻を編集） | この開催回の開始時刻を変えます。[開催日と開始時刻を変更する](edit.md)へ進みます。 |
| ⑧ | 開催日を変更 | この開催回の日付だけを変えます。[開催日と開始時刻を変更する](edit.md)へ進みます。 |
| ⑨ | 告知テンプレートを作成 | X 向け告知文のひな型を作ります。作成後は、そのひな型の名前がボタンに出ます。[自動告知との違い](auto-post.md)も確認します。 |
| ⑩ | 以降のイベントも削除する／カレンダーから削除 | **主催者だけ**の操作です。発表情報も消えるため、先に[削除の範囲](delete.md)を読みます。 |
| ⑪ | 記事／紐づけ用リンクを作成／編集／削除／記事生成 | 「記事」は発表の詳細を開きます。「紐づけ用リンクを作成」は登録済み発表を本人のアカウントにつなぐ入口です。「編集」「削除」は**発表 1 件**の操作です。[発表情報を登録する](../lt/create.md)と[ブログ記事を自動生成する](../lt/auto-generate.md)を読みます。 |
| ⑫ | 申請内容／承認／却下 | 「申請内容」で申請を読みます。「承認」「却下」は確認画面を開きます。[発表申請を承認・却下する](../lt/approve.md)へ進みます。 |
| ⑬ | 発表を追加 | この開催回に発表を登録します。[発表情報を登録する](../lt/create.md)へ進みます。 |

⑪ の「記事生成」は、PDF や動画があり、記事が未生成の時に出ます。
「紐づけ用リンクを作成」は、本人と未連携の承認済み発表に出ます。
⑫ の「承認」「却下」は、承認待ちの発表だけに出ます。

「VRCイベントカレンダーに投稿」がある場合は、外部の登録フォームを開きます。
Hub の「イベント登録」とは別の操作です。
開いただけでは投稿されず、入力内容を確認して外部側で送信します。

![スマホのイベント管理で上部メニュー①〜⑥、開催回⑦〜⑩、発表⑪〜⑬の場所を赤枠で示した縦長の地図](images/event/manage-02-sp.webp)

スマホでは、①〜⑥ の下に開催回、続いて発表の操作が並びます。
PC と同じ番号を上の表で確認します。

### 3. 先の開催回を表示する

近い予定から 2 回分が先に表示されます。
それより先を探す時は、下へスクロールします。

![先の開催予定を広げる「もっと見る」ボタンに①の赤枠がある画面](images/event/manage-03.webp)

① の「もっと見る」を押すと、先の予定が開きます。
「閉じる」を押すと、再び折りたたまれます。
過去回は未来の予定より下で探します。

![スマホで先の予定を開く「もっと見る」①を赤枠で示した画面](images/event/manage-03-sp.webp)

スマホでも ① を押して、先の開催回を探します。

## うまくいかない時

### 集会名がメニューに出ない

主催者からスタッフ参加の案内を受けたか確認します。
別のアカウントでログインしていないかも確認します。
集会が閉鎖されている場合は、[集会を閉鎖・再開する](../community/close.md)を読みます。

### 変更するボタンが出ない・押せない

過去回は、日付と開始時刻を変更できません。
Vket コラボ（複数の集会が参加する企画）の対象回は、変更が制限される場合があります。
表示された案内を読み、日程調整が必要なら Hub 運営へ相談します。

### 削除ボタンがあるのに削除できない

スタッフにもボタンは表示されますが、削除できるのは主催者だけです。
⑩ は開催回全体、⑪ の「削除」は発表 1 件の削除です。
