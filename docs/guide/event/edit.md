# 開催日と開始時刻を変更する

登録した開催回の、日付や開始時刻を変更します。
日付と時刻は、別々の画面で保存します。

## 始める前に

- 主催者かスタッフとしてログインします。
- [イベント管理](manage.md)で、変更する集会を開きます。
- 過去の開催回は変更できません。
- Vket コラボの対象回は、変更が制限される場合があります。
- 両方変える場合は、日付を変更した後、時刻を変更します。

## 手順

### 1. 日付を変更する開催回を選ぶ

イベント管理で、現在の開催日と開始時刻を確認します。
日付を変えない場合は、手順 3 に進みます。

![対象の開催日と開始時刻の下にある「開催日を変更」を①の赤枠で示した画面](images/event/edit-01.webp)

① の「開催日を変更」を押します。

### 2. 新しい開催日を保存する

「現在の開催日時」が、変更したい開催回か確認します。

![「開催日を変更」画面の新しい日付欄①と「変更する」②を赤枠で示した画面](images/event/edit-02.webp)

① で本日以降の日付を選び、② の「変更する」を押します。
イベント管理に戻り、変更した開催日を探します。
開始時刻は変わりません。
画像の日付は架空の例です。

**定期開催でも、この開催回だけの日付変更です。**
基になる「親イベント」を動かしても、登録済みの子開催回や定期ルールは変わりません。
移動前の日付は、自動で作り直されないよう記録されます。

### 3. 開始時刻の変更画面を開く

変更する開催回の「開始時刻」の右側を見ます。
時刻を変えない場合は、ここで終了です。

![開催回の開始時刻の右側にある鉛筆アイコン「開始時刻を編集」を①の赤枠で示した画面](images/event/edit-03.webp)

① の鉛筆アイコンを押します。
「開始時刻の変更」が開きます。

### 4. 新しい開始時刻を保存する

集会名と開催日を確認します。

![「開始時刻の変更」画面の時刻欄①と「保存」②に赤枠がある画面](images/event/edit-04.webp)

① に新しい時刻を入れ、② の「保存」を押します。
イベント管理に戻り、開催回と発表の時刻を確認します。

**この開催回にある発表の開始時刻も、同じ分数だけ動きます。**
例: 開催回を 22:00 → 22:30 にすると、22:10 の発表は 22:40 になります。
他の開催回の開始時刻は変わりません。

## うまくいかない時

### 鉛筆や「開催日を変更」が見つからない

過去回には、変更ボタンが出ません。
集会名と、対象の開催日を確認します。
Vket コラボの変更制限が出る場合は、Hub 運営へ相談します。

### 同じ日時のイベントがあると表示される

同じ集会・開催日・開始時刻は重ねられません。
既存の開催回を確認し、重ならない日時にします。

### Google カレンダーの更新に失敗したと表示される

「変更自体は保存済み」「後続の同期で再反映」などの案内を読みます。
Hub の変更後の日時を確認し、カレンダーは次の同期後に確認します。
繰り返し失敗する場合は、案内文と対象の開催日を Hub 運営へ伝えます。

### タイトル・場所・開催時間も変えたい

この 2 つの画面には、日付と開始時刻以外の編集欄はありません。
集会の紹介情報は、[集会情報を編集する](../community/edit.md)で変更します。
発表のテーマや内容は、発表側の「編集」を開きます。
