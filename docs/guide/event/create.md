# イベントを登録する

集会の開催イベントをカレンダーに登録する手順を説明します。

## イベント登録とは

イベントを登録すると、以下の場所に反映されます。

- VRChat技術・学術系イベントHubの「開催日程」ページ
- 技術・学術系イベント共有Googleカレンダー
- 各集会の詳細ページ

## 事前準備

イベントを登録する前に、以下を確認してください。

- 集会が登録・承認済みであること
- 主催者またはスタッフとしてログインしていること

## 登録手順

### 手順1: イベント登録ページを開く

1. ログイン後、画面右上のアカウントメニューの「集会一覧」から対象の集会を選び、イベント管理画面を開く
2. 「イベント登録」ボタンをクリック

### 手順2: 基本情報を入力する

#### 必須項目

| 項目 | 説明 |
|------|------|
| 開始日 | 初回開催日。開催周期の曜日・日付・週と一致する日を選びます |
| 開催周期 | 単発・毎週・隔週・毎月の日付指定・毎月の第N曜日（最終を含む） |
| 開始時刻 | イベントの開始時刻 |
| 開催時間（分） | イベントの長さ（集会設定のデフォルト値が初期入力されます） |

### 手順3: 確認して登録

入力内容を確認し、「登録」ボタンをクリックして完了です。

## Googleカレンダーへの反映

登録したイベントは、技術・学術系イベント共有Googleカレンダーに自動的に反映されます。

### 反映のタイミング

- 共有Googleカレンダーには定期同期後に反映されます

### カレンダーの購読

参加者はこのGoogleカレンダーを購読することで、すべてのイベント情報を自分のカレンダーで確認できます。

## VRChatイベントカレンダーへの投稿

登録したイベントは、VRChatイベントカレンダーにも投稿できます。

### 投稿手順

1. アカウントメニューの「集会一覧」から対象の集会を選び、イベント管理画面で対象のイベントを表示
2. 「VRCイベントカレンダーに投稿」ボタンをクリック
3. イベントカレンダーの登録フォームが開き、情報が自動入力されます
4. 内容を確認してフォームを送信

## 定期開催の設定

毎週同じ曜日に開催する場合は、定期開催の設定が便利です。

### 設定方法

1. イベント登録画面で初回開催日・開始時刻・開催時間を入力する
2. 「開催周期」を選び、必要な曜日・日付・週を指定する
3. 登録すると、初回から約3か月分の開催予定が生成され、以後は定期処理で追加されます

登録した開催情報は集会情報にも反映されます。ただし、定期開催中の集会に単発イベントを追加しても、既存の開催周期・曜日・時刻・開催時間は変更しません。継続生成には、その定期イベントの親に登録された開始時刻・開催時間を使います。月の日付指定は28日以前を選んでください。定期登録の初回開催日に既存イベントがある場合は登録できません。

集会を再開した場合も、再開完了画面の「開催予定・開催周期を登録する」から設定してください。再開だけでは古い開催予定は復元されません。

## よくある質問

### Q: 登録したイベントを編集したい

イベント一覧から対象のイベントをクリックし、「編集」ボタンから変更できます。

### Q: Googleカレンダーに反映されない

以下を確認してください。

- 集会が承認済みかどうか
- 開催日が過去の日付になっていないか

問題が続く場合は、管理者にお問い合わせください。

### Q: 同じ日に複数のイベントを登録できますか？

はい、同じ集会でも異なる時間帯であれば複数のイベントを登録できます。
