# Issue #570 終了済み Vket バナー調査

## 原因候補と確認した事実

候補は、コラボのフェーズが終了後に `ARCHIVED` へ更新されないこと、またはバナー表示が開催期間を確認していないことだった。`EventMyList._get_vket_banner` は `DRAFT` と `ARCHIVED` だけを除外し、`ENTRY_OPEN` では開催終了後でも申し込みバナーを返していた。開催中判定には `period_start <= today <= period_end` を使う一方、終了後を非表示にする分岐はなかった。

## 採用案

コラボ選択クエリに `period_end__gte=timezone.localdate()` を加え、終了済み候補を除外してから最新のコラボを選ぶ。終了日当日は候補に残し、翌日から非表示にする。これにより、より新しい開始日の終了済みコラボが開催中コラボを隠すことも防ぐ。

## 却下案

終了時にフェーズを `ARCHIVED` へ自動更新する案は、バナー表示だけの要件に対して状態遷移・運用ジョブの範囲を広げるため採用しない。テンプレート側で非表示にする案も、コンテキストが終了済みコラボを表す不整合を残すため採用しない。

## 検証手順

`period_end` が昨日の `LOCKED` コラボでは `vket_banner` が `None` になること、終了日当日の `LOCKED` コラボでは「開催中」バナーが表示されることを回帰テストで確認する。さらに、より新しい開始日の終了済み `ENTRY_OPEN` コラボと開催中 `LOCKED` コラボが共存しても、開催中コラボのバナーを返すことを確認する。
