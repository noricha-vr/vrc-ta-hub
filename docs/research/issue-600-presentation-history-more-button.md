# Issue #600 発表履歴「もっと見る」ボタン配置調査

## 原因候補と確認した事実

集会詳細テンプレートでは、発表履歴セクションの「もっと見る」リンクを囲む要素に Bootstrap の `text-end` が指定されていた。そのためリンクはカード右端に配置されていた。リンク先は `event:detail_history` と集会名のクエリ文字列で構成されており、配置とは独立している。

## 採用案

発表履歴セクションのラッパーだけを `text-center` に変更する。既存の Bootstrap ユーティリティを使うため追加 CSS は不要で、リンク先やボタンの見た目も維持できる。

## 却下案

専用 CSS クラスを追加する案は、Bootstrap で同じ配置を表現できる変更に対して管理対象を増やすため採用しない。活動履歴セクションにも同じ変更を広げる案は、今回の要望範囲を超えるため採用しない。

## 検証手順

Community view の既存テストで集会詳細ページの生成が回帰していないことを確認する。さらに使い捨て環境で過去の発表を持つ集会詳細ページを表示し、発表履歴のボタンが中央揃えであること、リンクが発表履歴一覧へ遷移することをデスクトップ幅とモバイル幅で確認する。

## 検証結果

Community detail view の既存テスト7件はすべて成功した。使い捨てコンテナで表示した集会詳細ページでは、デスクトップ幅でボタンとラッパーの中心座標が一致し、モバイル幅でも中央配置を確認した。「もっと見る」のクリック後は、集会名クエリを維持した発表履歴一覧が HTTP 200 で表示された。
