# Issue #566 協力団体の公開審査基準

## 調査根拠

既存の公開静的ページは `TemplateView` と `ta_hub/base.html` を使い、集会登録は
`community:create`、全ページ共通フッターは同じベーステンプレートから提供している。
Issue #566 で確定した定義、必須条件5項目、4つの評価軸と承認可能ラインを公開情報の正本とする。

## 採用方針

`/community/criteria/` に未ログインで閲覧できる静的ページを追加する。技術系・学術系・協力団体の
定義と対象例・対象外例を示し、協力団体については必須条件と0〜2点の評価基準を分けて掲載する。
集会登録ページと共通フッターから同ページへリンクし、審査前に基準へ到達できるようにする。

## 検証手順

`community.tests.test_criteria_page` を実行し、未ログインでの200応答、要点見出しと承認可能ライン、
集会登録ページおよび共通フッターからのリンクを確認する。
