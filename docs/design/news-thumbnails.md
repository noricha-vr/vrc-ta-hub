# お知らせのサムネイルの使い分け

2026-10-31 に、一覧・カテゴリ一覧のカードと記事詳細の見出し画像は「リッチ版」にする方針を決めた。左に見出し、右に記事の中身が分かるスクリーンショット・動画サムネイル・表紙などを置く。

## 現在の配信

- リッチ版の定義は `app/news/thumbnail_specs.py` の `RICH_POST_THUMBNAIL_SPECS` に置く。指示が無い新記事でも、エージェントが記事に合う画像を選んでリッチ版を作る。
- リッチ版を含む slug 個別画像が無い記事は、カテゴリ既定の文字画像を使う。カテゴリも未定義ならサイト共通の既定画像を使う。
- 通常は `Post.thumbnail` の手動アップロード画像 > slug 個別画像 > カテゴリ既定の順に使う。
- `prefer_over_upload=True` を明示した slug だけは static のリッチ版がアップロード画像より優先する。対象は `2026-10-31-misskey-account`、`vket-2025-summer`、`vket-2025-winter`、`vrchat-nyumon-2025` の 4 本。DB のアップロード画像は変更しない。
- 現在の共有画像（記事詳細の `og:image` / `twitter:image`）も同じ選択結果を使う。下記のめいゆん版への分離は未実装。

## 作成と点検

`scripts/news_rich_thumbnails/README.md` の手順で素材を集め、リッチ版を作る。素材はリポジトリに含めない。見出しの大きさ・画像との重なり・画像のはみ出し・面積の自動点検に加え、1 枚ずつ見せたいところと見出しが合っているかを目で確かめる。一覧のカード幅（約 400px、16:9 に切り抜き）でも読めるか確認する。

配信用画像は 1200×630 の JPEG（品質 86）にし、`app/news/static/news/images/og/` に置いて定義を更新する。static はハッシュ無しの URL でキャッシュされるため、作り直す時は必ずファイル名の `-vN` を上げる。既存の文字画像・カテゴリ既定画像は、キャッシュ済み URL のため削除しない。

文字だけの生成器 `news.thumbnail_generator` と `scripts/generate_news_thumbnails.py` は残す。生成対象は `POST_THUMBNAIL_SPECS` とカテゴリ既定 2 枚だけで、リッチ版は `--force` でも上書きしない。現在の記事定義はすべてリッチ版へ移したので、文字だけの生成対象はカテゴリ既定 2 枚。新記事のリッチ版が準備できるまではカテゴリ既定を使う。

## 共有画像のめいゆん版（2026-10-30 の案・未実装）

| 置き場所 | 方針 |
|---|---|
| X・Discord などで共有された時の画像（記事詳細の `og:image` / `twitter:image`） | 将来、めいゆん＋タイトルの画像へ分離する案 |
| お知らせ一覧・カテゴリ一覧のカード、記事詳細の見出し画像 | リッチ版を使う（2026-10-31 決定） |

めいゆん版は集会・ガイドの共有画像と見た目が揃い、タイムラインでサイトの告知だと分かりやすい。一方で一覧は、画像から記事の内容を見分けられることと、見出しの読みやすさを優先する。手動アップロードと明示的な static 優先指定の扱いは、共有画像を分離する実装時にも維持する。

### 将来の実装時の要点

- 素材は `app/ta_hub/og_assets/` にカテゴリごとのフォルダ（例: `news-update`、`news-activity`）を作る。ガイドの素材のラベルを「アップデート」「活動履歴」に変え、`base.json` の `text_box` はガイドと同じにする。
- `ta_hub.og_image.render_text_png` で描画し、`ta_hub/views_og.py` に記事用 URL（例: `og/news/<slug>.png`）を足す。公開済みの記事だけを対象にする。
- 記事詳細の `og:image` / `twitter:image` だけを新 URL に向ける。一覧・詳細の見出し画像で使う `get_thumbnail_url()` はリッチ版の選択に使い続ける。
- 長いタイトルで末尾の 1 文字だけが次の行に残らないか、実際の記事で折り返しを確認する。
- 改題で共有画像も変わるため、X・Discord のキャッシュを考慮し、URL に更新日時などの版を付ける方法を決める。
